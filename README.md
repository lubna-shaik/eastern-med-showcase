# Eastern Med Showcase

Create a professional, modern, premium corporate website for a medical supplies company called:

EASTERN MED SUPPLIES

Tagline:
"Better Supplies. Healthier Tomorrow."

I want the website to take structural inspiration from this reference website:
https://sites.google.com/view/pioneersourceformedical/home

Do NOT create a pixel-for-pixel copy. Use the reference only to understand the type of company website, information hierarchy, and general sections. Create an original, significantly more polished and modern design for Eastern Med Supplies.

========================================
BRAND IDENTITY
========================================

Use the provided Eastern Med Supplies logo as the primary brand reference.

Brand colours should be based on the logo:

- Medical blue
- Deep blue
- Teal / medical green
- White
- Very subtle soft pink/blush as an optional secondary accent

White should be the dominant background colour.

The overall design should feel:

- Professional
- Premium
- Trustworthy
- Modern
- Healthcare-focused
- Clean
- Corporate
- Elegant
- Spacious

Do NOT make the website overly colourful.

Do NOT use excessive gradients.

Do NOT make it look like a generic template.

Do NOT make it look like an e-commerce website.

========================================
WEBSITE PURPOSE
========================================

This is a company profile and medical product catalogue website.

There is NO:

- Shopping cart
- Online payment
- User login
- Customer registration
- Checkout
- Order management
- Complex backend
- Database

This is primarily a FRONTEND / STATIC BUSINESS WEBSITE.

Customers should be able to:

- Learn about the company
- View product categories
- View individual products
- Learn about services
- Contact the company
- Send an enquiry by email
- Call the company
- Open WhatsApp if a number is provided
- View the company location
